# P1.5 强化基线实验报告（真实结果）

数据与切分与 P1 完全一致（370 样本 / 时序 70-15-15：train 259 / val 55 / test 56；Walk-Forward 相同 4 折扩张窗口）。全部预处理（imputer/scaler/类别权重计算）只在各自 train 上 fit。

## 0. 本轮实验纪律改动

- LR pipeline：`Imputer → StandardScaler → LogisticRegression`（scaler 只 fit 当前 train，walk-forward 每 fold 独立重训——测试锁定）。
- 全 NaN 特征：8 个（4 周期 × `divergence_strength`、`fractal_price`，结构性缺失，见 docs/feature-cleanup-report.md）在 fit 时按 train 观测从 feature matrix 剔除，原始 Dataset 未修改。
- 新增 LightGBM 4.7.0 / XGBoost 3.2.0 基线（保守默认参数：300 树、lr=0.05、depth=4）；类别权重变体为独立实验。
- XGBoost 3.x 需要数值标签（scale_pos_weight 路径），已实现 LONG→0/SHORT→1 映射。

## 6. 明确回答十个问题

1. **StandardScaler 是否改善 LR？** 否。收敛 warning 消除，但 LR 全面退化：全局 test acc 0.661→0.536、log loss 0.560→1.408；WF mean acc 0.625→0.547。可能原因：未标准化时 lbfgs 不收敛，模型停留在接近先验的欠拟合状态，恰好隐式正则；标准化后完全收敛，在 259 样本 × 192 维上过拟合。**结论：该数据集上标准化对 LR 有害**（保留 scaler 作为纪律性组件，但性能结论以实验为准）。
2. **LR balanced 是否仍然有效？** 否。P1 的 0.714 不复现（scaler 版本下 balanced 0.464 反而不如 default）。
3. **RF 是否真的比 LR 稳定？** 是。WF：f1 0.617 vs 0.489、log loss 0.630 vs 1.390、worst trader f1 0.512 vs 0.325；四个 fold 全部优于同 fold 的 LR。
4. **LightGBM 是否超过 RF？** 否（WF f1 0.541 < 0.617；test f1 0.535 < 0.594）。
5. **XGBoost 是否超过 RF？** 否（WF f1 0.551；test f1 0.364——全局 test 上最差）。
6. **哪个模型 Walk-Forward 最稳定？** RF（mean f1 最高、log loss 最低、worst-trader f1 最高；std 0.065 属于中等但均值优势明显）。
7. **哪个模型 Test 最好？** RF 默认权重（0.607/0.594/0.775）。
8. **Chan + Geometry 的增益是否仍然存在？** 在 LR+scaler 下**不存在**（Market Only 最优）。树模型的 importance 显示 RF/LGBM/XGB 确实在消费 chan/geometry 特征，但本阶段未做树模型消融，无法声称增益。诚实结论：增益依赖模型与预处理，当前不成立。
9. **Trader ID 是否仍然没有增益？** 是，仍无增益（full 与不含 trader 的集合指标完全相同）。
10. **是否有足够证据进入 Trader Embedding？** 否。trader one-hot 无增益、370 样本、主要误差来自时间漂移；当前没有任何证据支持 Trader Embedding。

## 7. 下一步建议（不做复杂化）

GBDT 没有明显超过 RF/LR，按纪律不继续复杂化。下一步：① RF 特征消融（树模型上验证 chan/geometry 真实增益）；② 收集更多历史数据；③ 漂移监控（fold label 分布）；④ 如做选择，仅基于 Train/Validation。
